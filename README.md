# Smart Autocomplete Engine

A Python-based statistical autocomplete system that predicts and ranks word suggestions using traditional NLP algorithms.

## Features

- **Next-word Prediction:** Unigram, Bigram and Trigram language models.
- **N-Gram Backoff:** Uses shorter contexts when longer contexts are unavailable.
- **Word Completion:** Trie-based prefix matching.
- **Spelling Correction:** Levenshtein edit distance.
- **Personalization:** Learns word frequencies from user input.
- **Suggestion Ranking:** Combines statistical frequency and personalization scores.
- **Terminal Interface:** Interactive command-line interface.

## Technologies Used

- Python
- Natural Language Processing
- N-Gram Language Models
- Trie Data Structure
- Dynamic Programming
- JSON

## Dataset

Trained on approximately 2.48 million words from a collection of English text files, including literary and conversational text.

## How to Run

1. Clone this repository.
2. Ensure Python is installed.
3. Open the project directory in your terminal.
4. Run:

```bash
python main.py
```

## Algorithms

- Unigram, Bigram and Trigram frequency counting
- Trigram-to-Bigram-to-Unigram backoff
- Trie-based prefix searching
- Levenshtein distance
- Frequency-based personalized ranking

## Limitations

This is an educational statistical autocomplete prototype. Its predictions depend on the training corpus and are not generated by a neural language model.
